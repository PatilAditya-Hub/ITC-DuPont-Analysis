# ITC DuPont Analysis

This project presents a DuPont Analysis of *ITC Ltd* from FY2019 to FY2024.

### About the Company
ITC Ltd is a diversified Indian conglomerate with businesses in FMCG, hotels, paperboards, packaging, agribusiness, and information technology.

### Objective
The aim of this analysis is to break down the Return on Equity (ROE) into its key drivers using the DuPont formula:
*ROE = Net Profit Margin × Asset Turnover × Financial Leverage*

### Tools Used
- Excel
- Screener.in (for data collection)

### Key Insights
- ROE improved significantly from 21.31% in FY21 to 29.60% in FY23, showing strong profitability.
- Net Profit Margins and Asset Turnover ratios both increased, indicating operational efficiency.
- Financial Leverage remained stable around 1.24x, suggesting balanced risk.

### Files Included
- ITC-DuPont-Analysis.xlsx — Raw data + DuPont formula calculations
- ITC Ltd DuPont Analysis.pdf — Final summarized report
